# v5.1.1 原字形复用修复

基于已交付的 v5.1 修复，原 ZIP 未覆盖。

- 原字形按自身像素宽度、顶部和高度排版，不再使用所选字体的字符宽度。
- 字号按源字形参考字号等比例缩放，字距、换行、透明度、旋转、柔化及描边进入统一渲染。
- 原字形字重固有；需加粗可用描边，不能无损生成源图没有的另一字重。
- 联网 OCR 接口若返回 symbols 单字符坐标，现在会保留并校验，不再丢弃。
- 无 symbols 时，对清晰且分离的单行字符尝试像素投影切分；粘连、断裂、数量不符时明确拒绝，避免错配。
- 添加文字没有源字形；选区里没有的新字符仍不能凭空复用。请选择字体重绘或选中包含所需字符的源图区域。

联网接口可附加：
```json
{"lines":[{"text":"2026","confidence":98,"r":{"x":10,"y":20,"w":100,"h":40},"symbols":[{"text":"2","b":{"x":10,"y":20,"w":20,"h":40}}]}]}
```
各字符 b 坐标是原图坐标，必须位于该行 r 内。其余启动、联网隐私与接口要求见 README-v5.1.md。

验证：原有 test-all.cjs 与纯布局测试通过；Edge 无头真实 Canvas 验证原字形提取、重复数字、字体独立排版、2 倍缩放像素边界、400 字符换行、预览/应用/撤销/恢复、无坐标自动切分及缺字/粘连错误提示。联网坐标保留用模拟接口验证，未连接真实外部服务。并重新运行 v5.1 浏览器回归。

运行浏览器测试需安装 playwright、可用 Edge，先启动 server.cjs：
- node test-glyph-browser.cjs
- node test-v51-browser.cjs

不宣称任意低清、复杂背景或粘连字形都能准确切分。
