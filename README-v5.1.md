# Text Studio v5.1 编辑引擎

基于用户提供的 V5 原包修改，保留原图/预览、标签页、字体导入、背景修复和 Photopea。

## 启动
1. 解压到普通目录，安装 Node.js。
2. 双击 start.cmd，打开 http://localhost:8787。
3. 打开图片后立即显示；默认免费 Tesseract OCR 在后台运行，首次仍需要下载模型。可直接添加文字，不必等待。
4. 点击 OCR 行或双击原图添加文字。编辑内容、字号、字距后预览自动更新。
5. 内容超过原 OCR 框不再报错：按剩余画布宽度换行，超出高度自动扩展透明画布。超大单字、旋转超边界也扩展画布；安全像素上限仍保留，防止内存耗尽。
6. 应用修改或直接导出 PNG。撤销/恢复按钮针对已应用图片状态，Ctrl+Z / Ctrl+Shift+Z 同效。输入框中快捷键保留浏览器原生文字撤销。

## OCR 架构
默认本地处理，不上传图片。自动模式不再逐个加载九种语言；仅使用简体中文/英语模型，不宣称自动检测语种。其他语言请手动选。
模型可复用，整图 OCR 串行后台执行。切换标签和关闭图片有结果归属/版本保护。
联网模式需用户自行提供已授权接口，无内置第三方密钥、无保证永久免费的公共服务。切换为联网即允许把图片上传至填写地址；不自动上传到其他服务，也不在失败后偷偷切换。

接口契约：POST multipart/form-data，image 为 PNG 文件，language 为 Tesseract 语言代码。
响应示例：
```json
{"lines":[{"text":"2026","confidence":98,"r":{"x":10,"y":20,"w":100,"h":30}}]}
```
坐标为原图像素，confidence 范围 0–100。服务器需支持浏览器 CORS。请求 30 秒超时。只允许 HTTPS 或 localhost/127.0.0.1。未配置接口会显示错误，图片仍可编辑。框选区域识别仍采用本地 OCR。

## 字体匹配
沿用字体候选与字重搜索，加入 OCR 数字/拉丁单字符区域的轮廓评分，减少仅依赖整行轮廓的偏差。结果是候选排序，不是已证明的精准字体识别；未知艺术字、缺失字体或 OCR 边界错误仍需人工核对。原字形复用仍只能使用源图已有字符。

## 验证
- node test-all.cjs：原有静态/DOM 引用、背景修复、模拟工作区/Photopea、TTF 检查通过。
- node test-v51.cjs：新增纯布局测试通过（长文本、字距、换行、Unicode）。
- node test-v51-browser.cjs：本机 Edge 无头真实 Canvas 页面验证通过；需 playwright 包和已启动服务。OCR 使用延迟模拟 Worker，不代表真实识别精度或网络下载验证。
- 联网接口、真实多语言 OCR 下载识别、Photopea 外部服务未做端到端验证。
- 旧 test-browser.cjs / test-flow.cjs 属于历史版本，包含“超出应拒绝”等旧断言，不作为 v5.1 发布门槛。

新增布局/渲染使用同一路径供预览、应用和导出；原 OCR 区域只负责清除旧字，不限制新字尺寸。应用仍为栅格化保存，而非完整可跨会话重新编辑的持久 TextLayer 文档。
