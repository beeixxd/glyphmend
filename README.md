# 字境 V4 · 图片文字工作台

## 启动与部署

本地双击 start.cmd，需要 Node.js 18 或更高。访问 http://localhost:8787。静态网站部署上传整个 dist 目录，使用 HTTPS。无后端、无构建步骤、无 API Key、无收费识别服务。

首次识别需联网下载免费 Tesseract.js 引擎与语言模型。可联网时运行 install-assets.ps1，把它们安装到 dist/vendor，再部署或离线使用本地编辑模式。当前交付包没有 OCR 二进制与字体文件，不能声称所有依赖已经内置。在线 Photopea 和在线字体加载需要联网。

## 文件与标签页

- 顶部“文件”菜单：新建画布、打开文件、导出 PNG、在线 Photopea、关闭当前标签页。
- 每张本地图片独立开一个标签页，支持多选打开、拖放多图、粘贴截图。同名图片也使用不同的内部标识。
- 新建支持名称、宽高、背景色与透明背景。
- 每个标签页分别保留画布、原图、选区、OCR、文字与样式、位置、预览、撤销历史、缩放和滚动位置。
- 关闭每个标签页都要求确认；只关闭网页内的文档，不删除本地文件。
- 每张图最多 1600 万像素 / 25 MB，所有标签页合计最多 4800 万像素，避免大量图片耗尽内存。网页刷新或关闭不保留工作区，需要先导出。

## 自动文字识别与匹配

打开图片自动识别原文；点击文字框或左侧文字行，或者框选区域自动识别，无需重输原文。

框选可选择“段落 / 多行”或“单行文字”。原文会自动填入，替换内容支持换行。按 OCR 行位置估算行距，结合轮廓比较给出候选字体、字号、字重、字距和颜色；按已加载字体实际的字重或可变字重范围比较；系统常规 / 粗体主要比较 400 / 700，可变字体可以覆盖 100–900。字号锁定，内容超出选区会提示，不会自动缩小。行距单位为原图像素，支持手动微调。

原字形复用只支持选中单行内已有字符；新字符和多行文字使用字体重绘。不改原文且自动样式未变化时保留原像素。所有字体匹配均是建议，不是从图片恢复了确定的字体型号。

无法识别的区域可创建“手动文字层”，或者切到 Photopea 使用文字、选区、修复、画笔与图层工具。手动文字层默认保留背景叠字，需要去除旧字时请选择背景修复或使用 Photopea。背景插值适用于纯色和平滑渐变，复杂背景可复制附近背景或用在线编辑器修复。

## 连续移动与拖动

Alt + ↑ / ↓ / ← / →：每次键盘事件移动 1 个原图像素，长按支持连续移动。没有加速步长，1000% 缩放仍保持 1 像素步长。

点击模式下拖动已选择文字框，即可移动文字。按原图坐标取整，鼠标移动不会因为画布缩放而改变像素计算。移动只作用于文字，背景修复留在原位置。预览区域自动扩大，图片边界停止移动。位置归零可重置。预览确认后点击“应用修改”再导出。

## 免费字体来源

1. 读取本机字体：桌面 Chrome / Edge 与 HTTPS / localhost，浏览器请求字体权限。
2. 批量导入 TTF / OTF / WOFF / WOFF2。TTF / OTF 可读取字体内部名称，便于传给在线编辑器；WOFF2 的内部名称未在本站解压解析。
3. 常用免费字体列表，可直接按 Google Fonts 名称加载，不需要 API Key。
4. 同步 Google Fonts 官方 GitHub 仓库 OFL / Apache / UFL 字体目录，按需获取字体元数据和字体文件；网络或 GitHub 未认证请求限流会影响同步，可重试、按名称加载或本地导入。同步目录不等于把所有字体文件下载到浏览器。
5. Photopea 自带免费字体数据库，还可接收本站当前选中的字体文件。

不存在可免费调用并覆盖全球所有字体的统一 API。商用字体、定制字体、未提供网络授权的字体不能凭空补齐。字体缺失、OCR 错误、艺术字、旋转/透视、阴影、压缩噪点与复杂背景都会影响还原，不能承诺任意图片百分之百一致。

## Photopea 图片往返

点击“在线 Photopea”在本网站的对话框内打开中文免费 Photopea，官方原版界面与字体库会保留。免费版本可能显示 Photopea 广告；没有接入收费去广告模式或收费 AI 功能。

默认发送完整合成图，并尝试传送当前所选字体。可勾选“重建可编辑文字层”后点重新发送当前图，把选中文字转为可编辑文字层。描边、模糊、旋转和原字形复用则使用完整合成图。未勾选重建文字层时，传入完整合成图。可编辑文字层仍须在 Photopea 核对字体及排版；创建失败会回退到完整合成图。不要把此功能理解成从任意位图无损恢复原始 PSD 文本图层。

按钮：返回本站（带回修改）、导出 PNG、导出 PSD、暂时切回本站、重新发送当前图、发送所选字体、重新加载。重新加载会确认，以免丢失在线未返回的修改。

同一会话暂时切回后再次进入，尽量恢复对应 Photopea 文档。若本站图像或编辑参数变化，会把当前状态重新传入新文档。返回本站使用 PNG 合成图更新原标签页，并可以撤销此次返回；要保留原生图层，请导出 PSD。修改后返回无需重新上传。

调用限制：只接受 www.photopea.com 且来自对应 iframe 的消息，返回文件核对标签页 source 标识，防止覆盖另一张图片。PNG 文件签名、体积与像素尺寸会验证。本站本地 OCR 在浏览器处理图片；打开在线编辑器时，图片与所选字体交由第三方 Photopea 网页处理。此在线功能不承诺完全离线或第三方站点零外部请求。
