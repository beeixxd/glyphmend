# 字境 Text Studio V6 · 图片文字工作室

打开图片 → 自动识别文字 → 自动匹配**字体 / 字号 / 字重 / 字距 / 倾斜** → 输入新文字，**右侧预览实时跟随**，**原图始终在左侧并排对照**。

## 启动

- Windows：双击 `start.cmd`（需要 Node.js 18+），自动打开 http://localhost:8787
- macOS / Linux：`./start.sh`
- 静态部署：上传整个 `dist` 目录（HTTPS）。无后端、无构建、无 API Key。
- `dist/vendor` 已内置全部识别引擎与模型（约 46 MB），**不联网也能识别**。首次识别要加载模型，PaddleOCR 约需数秒。

> 必须通过 http(s) 打开（脚本是 ES 模块 + Worker），不能直接双击 index.html。

## 和 V5 相比改了什么

| 你提出的问题 | V6 的做法 |
|---|---|
| 要有原图和预览图对照 | 左右 / 上下 / **滑动** / **差异热力图** / 仅预览 五种布局；两侧共用一个滚动区和缩放，鼠标悬停有联动十字准星；≥400% 像素化、≥800% 显示像素网格 |

| 字体粗细和原图不一致 | 见下节「字重如何对齐」 |

| 参考 GitHub 同类项目 | 见下节「参考与借鉴」 |

## 字重如何对齐

1. 从选区提取文字蒙版 α，量出原图的**笔画粗细**（面积 ÷ 周长，对抗锯齿和模糊稳健）、**倾斜角**（剪切投影能量最大化）、**亚像素墨迹框**。
2. 对每个候选字体和字重，按原行墨迹高度反推字号、按宽度反推字距，用**与最终渲染完全相同的路径**绘制并与原图蒙版比较（容忍亚像素错位）。
3. 第一轮就对每个候选做「字重归一」，避免只有字重刚好对上的字体才能入围。
4. 对前几名做**连续字重微调**（`字重微调 ±px`：加粗用描边、变细用沿轮廓擦除）、**柔化**（模拟降质截图）和 **±0.5px 亚像素位置**搜索。
5. 因此即使电脑里没有 500 / 600 这类中间字重，笔画粗细也能对上；右侧会显示「笔画粗细 原图 x px → 重绘 y px」。

三种绘制方式：
- **字体重绘**：任何新文字都可以。
- **复用原字形**：直接使用原图里该字符的真实像素，**原字符保持原图里的真实位置（含字距调整）**；缺字会明确报错，不会凭空造字。
- **智能混合**（推荐改数字/少量字）：有的字用原字形，缺的字用匹配字体补画。

## 识别引擎

| 引擎 | 位置 | 特点 |
|---|---|---|
| PaddleOCR PP-OCRv4 | 本地（onnxruntime-web） | 中文强，不上传图片 |
| Tesseract | 本地 | 拉丁 / 数字强，提供精确逐字框 |
| 视觉大模型（可选） | 你配置的服务商 | 校对文字，并给出粗体 / 斜体 / 字体族提示；**不决定文字位置** |

- 本地引擎各自检测后，按位置合并并**加权投票**；有分歧的行会标「有分歧」，右侧可点候选切换。PaddleOCR 丢英文词间空格、Tesseract 在汉字间乱加空格，已在融合层分别处理。
- 视觉大模型把各行截图拼成**一张**带序号的图，一次请求逐行校对；与本地结果差异过大时视为幻觉，**拒绝并保留为候选**。
- 预设：Google Gemini、智谱 GLM（Flash 系列）、硅基流动、OpenRouter（:free 模型）、**Ollama / LM Studio（本机，完全免费且数据不出电脑）**、自定义 OpenAI 兼容接口。
- 免费额度、免费模型名和是否把数据用于训练，各服务商**经常变化**，请以其官网为准；模型名可以自己改。图片由浏览器直接发给你填写的地址（本站无中转），仅允许 HTTPS 或 localhost。Key 默认只放内存，勾选「记住」才写入本机 localStorage。

## 其它功能

- 多标签页、拖放 / 粘贴 / 多选打开；新建画布；PNG / JPG / WebP 导出、复制到剪贴板；
- 非破坏式**文字图层**：显示 / 隐藏 / 删除 / 还原；撤销 / 恢复（Ctrl+Z / Ctrl+Shift+Z）；「合并图层」把结果烘焙为新底图；
- 描边、投影、柔化、旋转、不透明度、对齐、行距、自动换行；
- **批量查找替换**（支持正则，一次撤销）；框选识别；双击空白处添加文字；
- 背景修复：智能修补**仅文字像素**（保留背景纹理）/ 矩形平滑 / 纯色 / 复制附近背景 / 保留；
- 字体来源：系统字体自动探测、读取本机全部字体、批量导入 TTF/OTF/WOFF/WOFF2、免费在线字体（Google Fonts）、同步 google/fonts 目录；
- 在线 Photopea 往返（发送合成图与所选字体，修改后带回为新底图，或导出 PNG / PSD）。

快捷键：`Alt+方向键` 每次 1 原图像素微移（长按连续）；`Esc` 取消选择；`Ctrl+Z` 撤销。

## 能做到与做不到

- 字体匹配是**最相近的候选**，不是还原出原字体型号；艺术字、手写体、强透视 / 旋转、复杂背景、严重压缩会降低一致性。
- 免费字库不覆盖商用 / 定制字体；缺少原字体时请导入字体文件。
- 背景修补是经典插值，适合纯色 / 渐变 / 轻纹理；复杂图案背景请用「复制附近背景」或 Photopea。
- 结果是栅格像素，不是可跨会话重新编辑的 PSD 文本层。
- 本站不依赖也不包含任何收费识别服务。项目代码 MIT；第三方组件见 `THIRD_PARTY.md`。
