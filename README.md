# 字境 V3 · 免费本地图片文字编辑

双击 `start.cmd`，浏览器打开 http://localhost:8787。需 Node.js 18 或更新版本。部署时上传整个 `dist` 到静态网站，使用 HTTPS。

1. 打开图片，免费 Tesseract.js OCR 自动识别文字，图片在浏览器内处理。
2. 直接点击识别框 / 左侧文字行，或点击框选模式拖动圈住一行。原文自动填入，无需手动输入。
3. 仅输入替换内容。自动匹配候选字体、字号、字重、字距、颜色和原字形位置。
4. 可点击读取本机全部字体（Chrome / Edge 会请求字体权限）、批量导入字体，或联网加载 Google Fonts 免费 Noto Sans SC / Noto Serif SC。
5. 比较青色原字形与粉色候选轮廓。字号锁定，不会因为新文字较长自动缩小；超出选区会明确提示。
6. 原字形复用模式可使用这一行中已有的字符重新排列，避免重新选择字体。没有出现过的字符需要原字体或候选字体重绘。此模式保留字符轮廓，但颜色/透明度从背景估计，不承诺逐像素相同。
7. 预览、应用、1000% 检查、导出原尺寸 PNG；支持撤销。

## 免费与离线

无 API Key，无付费识别服务。首次运行需联网下载 Tesseract.js 6.0.1、WASM 与免费语言模型。OCR 不是生成式 AI，是本地识别模型。联网字体按钮只下载字体。

要真正离线运行，联网时在本目录运行：
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-assets.ps1
```
成功下载后会写入 `dist/vendor/ready.json`，应用改用本地引擎与模型。不要在依赖未齐全时手动创建此标记。在线字体是可选功能，离线可读取本机或导入字体。

当前交付包不包含 OCR 二进制/语言模型和中文字体文件；依赖安装脚本负责下载。本次环境阻止外部文件下载，因此不能声称依赖已打包，也不能声称真实 OCR 已验证。

## 精度边界

全球字体无法全部内置：大量字体有商用授权限制、自定义版本、不同字重和渲染差异。位图不包含原字体身份。OCR 也无法保证任意图片正确识别。字体匹配是字形像素轮廓比较，界面“形状差异”不是准确率。

目前按水平单行编辑，背景边缘插值适用于纯色和平滑渐变。艺术字、复杂背景、旋转/透视、描边/阴影、低清压缩图片不保证还原。复杂背景可使用附近复制；背景下原始内容已丢失，不能承诺无痕。

本版保持旧项目纯前端架构、画布/预览/导出和经典背景插值。重写旧版存在损坏的中文编码文件，不携带旧的失效离线 HTML。`start.cmd` 使用本地服务器提供资源，避免 file:// 下字体/OCR 限制。

## V3.1 像素移动
选中文字、填写新内容后，按 Alt + ↑ / ↓ / ← / →。每次按下移动 1 个原图像素，1000% 缩放也保持此步长。长按不会连发，避免移动过大。画面即时预览，点击应用后导出包含移动位置；位置归零可恢复原位置。只移动替换文字，背景修复区域留在原位置；移出原选区时自动扩大更新区域，到图片边界停止。
